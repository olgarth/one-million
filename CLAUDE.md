# One Million - інструкція для редагування

Застосунок для комісії частини щодо одноразової грошової винагороди 1 000 000 грн (п.4 постанови КМУ № 153 зі змінами № 387, № 942; доручення МОУ від 26.09.2025 № 5601/уд; роз'яснення ДСЗ МОУ від 08.12.2025 № 220/13/28126). Тільки Винагорода, не Допомога.

## Структура

- `index.html` у корені - ЗІБРАНИЙ файл, який роздає GitHub Pages. Руками не редагувати.
- `dev/src/` - модулі: `data_refs.js` (посилання, тлумачення INTERPS), `data_phrases.js` (формулювання документів, дефекти), `data_norms.js` (дослівні тексти норм, практика), `engine.js` (логіка evaluate / evaluateCert), `texts.js` (тексти документів), `ui.js`, `style.css`, `shell.html`.
- `dev/build.py` - збирання. `dev/tests/cases.js` - тести рушія. `dev/tests/icons.py` - значки (Playwright).
- `dev/research/` - дослідження норм, судової практики, формулювань (джерело для логіки).
- `manifest.webmanifest`, `sw.js`, `icons/` - встановлення як застосунку і офлайн.

## Після будь-якої зміни

```
node dev/tests/cases.js                               # усі тести мають пройти
python3 dev/build.py index.html <ДД.ММ.РРРР> pwa      # дата = "норми станом на"
```
Змінивши набір файлів для офлайну, підняти версію `CACHE` у `sw.js`.

## Правила

- Мова інтерфейсу і текстів - українська. Без довгого (—) і середнього (–) тире, лише "-".
- Тексти документів (висновок, наказ, відмова, довідка) беруть тільки title + text пунктів; поле `note` - лише для інтерфейсу, у документи не потрапляє.
- Персональні дані не зберігаються в localStorage (stripPD deep) і ніколи не потрапляють у репозиторій.
- Нова норма або позиція МОУ: спочатку `data_refs.js` / `data_norms.js`, потім логіка, потім тест у `cases.js`.
- Змінювати лише те, про що просить користувач; не переписувати структуру.
